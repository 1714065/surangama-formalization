## 命题与条件

- `InRoot`：阿难“了知心潜伏眼根里，如琉璃合”的解释成立。
- `SeesEye`：如见山河一样，将所称的眼当作可见色境；不是照镜子、照片等间接经验，也不是任何种类的认识。
- `FollowsSeeing`：保留阿难原说的根见、心随即分别的所依关系，不是任意一种分别活动。

| 条件 | 形式 | 来源及范围 |
| --- | --- | --- |
| 潜根则见眼 | `InRoot → SeesEye` | T19n0945 p107c01–04，琉璃比喻的迁移；`project-restatement` |
| 潜根须成随 | `InRoot → FollowsSeeing` | p107b27，模型要求保留“彼根隨見隨即分別”；`project-restatement` |
| 见眼不成随 | `SeesEye → ¬ FollowsSeeing` | p107c05，按所依根与所缘色境有别重建；`project-restatement` |
| 原简化版的不见眼 | `¬ SeesEye` | “何不見眼”反诘所采用；不是阿难另答“不见眼” |

所有条件都是定理参数。没有以定义隐藏目标，也没有另建一个已获无条件证明的佛教定义库。

## 三个反驳定理

| 定理 | 所用条件 | 中文证明 |
| --- | --- | --- |
| `not_in_root`（保留） | 潜根则见眼；不见眼 | 暂许潜根则见眼，与不见眼冲突 |
| `not_in_root_of_seeing`（新增） | 潜根须成随；见眼不成随；暂许见眼 | 暂许潜根则成随，但见眼又推出不成随 |
| `not_in_root_two_branches`（新增汇总） | 潜根则见眼；潜根须成随；见眼不成随 | 暂许潜根，其自身要求见眼，直接进入见眼分支反驳 |

汇总无需额外事实前提“不见眼”，也无需排中律；两种回答的反驳均有独立定理。
它是经文双分支的命题逻辑重建，不是经文全部语义和认知过程的形式化。
