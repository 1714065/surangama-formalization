# v1.0 release scope

The author selected v1.0 on 3 October 2026 and authorized public release on
4 October 2026. The scope is the existing C1–C7 formalizations, the shared
interpretation module, two bilingual preprints and the Chinese companion essay.

Public manuscript copies are in `manuscripts/`, with separate rights notices.
Private author-review files remain in the ignored `paper/` workspace and are
not release contents. Prior version tags and DOI archives remain intact.

See RELEASE_NOTES_v1.0.md and the GitHub v1.0 release for publication details.
