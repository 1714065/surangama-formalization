## 命题和主汇总

主汇总 `not_darkness_is_inner_sight` 否定的是：本次用见暗认内补救身内定位的解释 `Claim` 成立。它不是无条件否定所有心在内理论。

| 显式参数 | 工作含义与根据 |
| --- | --- |
| `Claim → Ordinary ∨ Inward` | 本次解释限于通常见暗认内、直接返观两路；项目分支范围 |
| `Ordinary → SeesDark ∧ InnerEvidence` | 通常解释声称见暗，并仅凭此确证见内；原说的重述 |
| `SeesDark → FacesEye` | 本段成见需根尘相对；p107c16 与圆瑛 P00661 |
| `FacesEye → ¬ InnerEvidence` | 此处相对所见的暗不确证暗就是内身；p107c14–15 的解释条件 |
| `Inward → SeesFace` | 同一返观能力开合一致，应能直接见面；p107c17–18，圆瑛 P00665 |
| `SeesFace → Outside` | 本段直接相对观看模型把心眼安排在身体外；p107c18–19 |
| `Inward → ¬ Outside` | 此补救仍要求身内定位，排除上述身外位置；补救初执的解释 |

`InnerEvidence` 指仅凭这里的暗境已确证看见自身内部，不指一切内身认识。`FacesEye` 是根尘相对关系，`Outside` 是身体外部位置；外尘的角色分类不能直接推出解剖位置。`SeesFace` 不指镜像、影像。

证明先按已列解释分类：通常见暗分支由成见关系与认内确证冲突而否定；返观分支由见面所需身外位置与所保留的身内要求冲突而否定。无须另加全局“不能见面”，也无须排中律。

## 后续追问与补充

| 定理 | 显式条件与范围 |
| --- | --- |
| `not_external_ownership_by_face` | 所用自身归属判据会把他者算作自身；他者非自身。迁移条件不由离体本身保证 |
| `not_two_knowers` | 二知导致“一身两佛”这一被质疑后果；不接受该后果。两者保留为含教义语境的条件，不定义佛 |
| `not_external_knower_rescue` | 外置独立能知补救导致身非觉或二知；身体有觉；再用二知的两条件 |
| `not_inward_via_knower_rescue` | 返观须见面、见面须身外、返观而身外须作外置补救；再接上一行四条件。是延长路线，不用主汇总的排除身外条件 |
| `not_darkness_criterion` | 仅凭暗认内的同一判据适用于暗室；室暗并非自身脏腑。独立补充，不进入主汇总 |

二知按本次注疏重建为两个分别独立的能知主体，不是视觉和触觉等多种功能。后续归属、二知、暗室反例不列作主汇总的必要依赖。不同分支中暂许的相反回答不同时当作全局事实。
