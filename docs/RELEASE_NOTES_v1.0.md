# v1.0 — shared conditional interpretation and public manuscripts

- Preserve all seven numbered C1–C7 modules and their 49 declarations.
- Add SharedNonduality.lean: eight declarations for the common exclusion,
  seven explicit bridges, transfer condition, consistency and omission witnesses.
- Include two research preprints in English and full Chinese translation,
  and one Chinese Buddhist-reader essay, in PDF/HTML/DOCX/Markdown.
- Explain the simpler shared proof structure: one exclusion schema and seven
  bridges instead of invoking seven original local premise packages.
- Retain explicit assumptions and the distinction between excluding a contextual
  self-mind identification and refuting a bare description or location.

The 57 declarations in the current local/shared layers have no extra axiom
dependencies; explicit premises remain. Historical Core models are separate.
Reproduce with the pinned Lean toolchain and `sh verify.sh`, or the Windows
tools plus both Python scope audits. This release is not journal acceptance.

Source/scripts: Apache-2.0; existing research documentation: CC0-1.0;
manuscripts: separate author-copyright notice in manuscripts/RIGHTS.md.
Private review backups and full dialogue records are excluded.
