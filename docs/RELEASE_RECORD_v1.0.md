## Contents and scope

Seven original C1–C7 modules (49 declarations), the shared interpretation module
(8 declarations), two bilingual research preprints, a Chinese companion essay,
and reproducibility materials. The five PDF language/article versions are also
direct GitHub download assets. Explicit interpretive premises remain; historical
Core models are outside the 57-declaration count. Public manuscript release does
not mean peer review or journal acceptance.

Code/scripts retain Apache-2.0; existing documentation retains CC0-1.0;
manuscripts retain their separate author-copyright notice. No private review
backups or full dialogue records are included.
